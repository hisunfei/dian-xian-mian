# 点线面 · 表象的本质

从设计元素到做事方法论的可视化探索。

## 项目简介

九大元素不只是视觉语言，更是一套认知和做事的方法：

- **点线面** — 从原子到系统，做事的结构
- **大中小** — 从主导到细节，做事的节奏
- **黑白灰** — 从强烈到调和，做事的力度

## 内容结构

### 第一幕：设计案例
从 NHK《啊！设计》节目的经典案例出发：
- 酱油瓶嘴（点）
- 电话线（线）
- 牛奶盒（面）

### 第二幕：方法论拔高
把点线面抽象为通用方法论：
- 点 = 找到元
- 线 = 建立连接
- 面 = 展开系统

### 第三幕：行业应用
四个行业案例展示同一方法的不同应用：
- 生产制造：零件 → 组件 → 成品
- 教育学习：知识点 → 知识线 → 知识面
- 软件开发：函数 → 模块 → 系统
- 写作表达：字/词 → 句/段 → 篇章
